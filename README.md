
# 🎓 Udemy Clone Website

## 📌 About the Project
This project is a simple Udemy Clone website developed using HTML and CSS. It is designed to recreate the basic layout and appearance of the Udemy online learning platform.

## ✨ Features
- Simple and user-friendly interface.
- Navigation bar.
- Search bar for courses.
- Course categories.
- Course cards with images and details.
- Responsive layout.

## 🛠️ Technologies Used
- HTML5
- CSS3

## 📂 Project Structure

```text
Udemy-Clone/
│
├── index.html
├── style.css
├── images/
└── README.md
```

## 🚀 How to Run
1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## 🎯 Project Objective
To develop a clone of the Udemy website interface and improve practical knowledge of HTML and CSS.
